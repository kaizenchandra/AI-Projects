# Model evaluation

The default split is 70% training, 15% validation, 15% final test using seed 42. The validation split chooses the candidate; Ridge and Lasso alpha are selected by 4-fold CV over development data. The final report is `reports/model_comparison.json`, generated by training rather than hand-written. It contains MAE, MSE, RMSE, R² and training duration for baseline, OLS, custom GD, Ridge, and Lasso.

The compact feature set is illustrative rather than a full appraisal model. It omits many Ames variables, does not establish causal relationships, and synthetic fixture scores must never be interpreted as real-world quality. For a real deployment, preserve geography/currency provenance, assess segment errors, monitor drift, and validate against recent labeled sales.
